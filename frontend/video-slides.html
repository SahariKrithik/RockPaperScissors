Part 2: let's build it for real!

We are making: Rock Paper Scissors

6 steps All free Works on Windows and Mac

How to talk to Claude

🍕Order like a pizza

Say exactly what you want, toppings and all!

🪜One step at a time

First the game, then the leaderboard, then the colors.

🩹Broken? No panic!

Copy the error, paste it to Claude, say "please fix this."

One important thing

🧑‍🤝‍🧑 Bring a grown-up

Claude accounts are for grown-ups, so ask a parent or teacher to sign in at claude.ai and build together. And always test your game after each change, because even robot friends make mistakes!

1🤖

Ask Claude to build the game

"Please build me a Rock Paper Scissors game website with a win-streak leaderboard."

For your grown-up helper

🪟 Windows and 🍎 Mac, exactly the same

Easiest: go to claude.ai in your browser and type what you want. To build like in this video: install VS Code from code.visualstudio.com, add the Claude Code extension, and Claude works right next to your files.

2🎒

Put the code in your backpack

go to github.com➜make a repository, your backpack➜put your game files inside

For your grown-up helper

🪟 Windows

The backpack is called a repository. Click "New repository", then "Add file" to upload. Prefer Git? Install it from git-scm.com.

🍎 Mac

Same buttons, all in the browser. Git is already built in if you want it: open Terminal and type git.

3🏠

Practice on YOUR computer

open the magic typing window➜say two magic words➜the game appears at localhost:3000

The magic words wake the game up on YOUR computer only.

For your grown-up helper

🪟 Windows

The magic typing window is PowerShell: click Start, type PowerShell, press Enter. Install Node.js from nodejs.org first, then the magic words are npm install and npm start.

🍎 Mac

The magic typing window is Terminal: press Cmd + Space, type Terminal, press Enter. Install Node.js from nodejs.org first, then the same magic words: npm install and npm start.

4🚀

Launch your game's face

go to vercel.com➜sign in with your backpack➜press the big Deploy button

Vercel gives you a magic link to share!

For your grown-up helper

🪟 Windows and 🍎 Mac, exactly the same

All in the web browser, nothing to install. Sign in with GitHub, click "Import" on your repository, then "Deploy". The shareable link appears when it finishes.

5🍳

Wake up the brain

go to render.com➜show it your repository➜press Deploy➜the backend wakes up

For your grown-up helper

🪟 Windows and 🍎 Mac, exactly the same

All in the browser. Click "New", choose "Web Service", pick the GitHub repository, then "Create Web Service". Render runs the game's brain day and night. When it finishes, copy the service URL and paste it into frontend/config.js as BACKEND_URL, then push - that tells the game's face where its brain lives.

6🗃️

Give your game a memory

make a free database, your memory box➜copy its secret key➜hand the key to Render

🔑 The secret key is like a house key. Never share it!

For your grown-up helper

🪟 Windows and 🍎 Mac, exactly the same

Go to mongodb.com/atlas and create a free cluster (the memory box). Copy the connection string (the secret key). In Render, open your service, click "Environment", and paste it there.
